# 宝藏盒 · Treasure Vault（原生 Android）

> Kotlin + 原生 View 的工具集合应用：没有 Flutter 引擎、没有 WebView、没有第三方 UI 框架，
> **138 个工具全部本地运行**，启动只构建首页视图。
>
> 安装包按 ABI 分包：arm64-v8a 约 14 MB、armeabi-v7a 约 9.8 MB（其中 OCR 原生库占大头，
> 换来端离线中文识别；其余代码与资源合计不到 4 MB）。

## 页面

| 页面 | 内容 |
| --- | --- |
| 首页 | 收藏（四宫格）+ 最近使用；打开工具页自动记录 |
| 全部 | 全部工具按分类分组，支持关键词搜索与分类筛选 |
| 我的 | 主题设置、深色模式、自动检查更新、更新记录、加速源、低内存模式、清除记录、关于 |

底部导航支持三种样式（图标+文字 / 仅图标 / 仅文字），在「主题设置」里切换。

## 主题设置（对齐 SunBuilder-grpc）

* 6 套配色：极简蓝 / 翡翠绿 / 海洋蓝 / 落日橙 / 紫罗兰 / 樱花粉
* 球体预览：上半为顶栏色、下半为画布色，选中卡片有主色描边
* 明暗模式：浅色 / 深色 / 跟随系统
* 底部导航显示模式：图标+文字 / 仅图标 / 仅文字

## 动画

* 页面切换：淡入 + 上移 8dp（低内存模式可关闭）
* 工具页打开/关闭：滑入 + 淡出
* 掷骰子：快速换面 + 缩放回弹 + 轻微摆动
* 抛硬币：3D 翻转（rotationY 1800°，配合透视与挤压）
* 随机抽签：老虎机式滚动，落定后逐条列出结果
* 做个决定：同样的滚动定格效果

## 架构与内存

```
app/src/main/kotlin/com/suibian/treasure_vault/
├── MainActivity.kt        三页框架 + 底部导航（只保留当前页 View 树）
├── core/                  设计令牌、UI 积木、Prefs、工具注册表、工具宿主
├── pages/                 首页 / 全部 / 我的 / 主题设置 / 更新记录 / 更新助手
└── tools/                 按类别拆分的工具实现
```

* 单 Activity + 原生 View，不引入 Compose：少了组合树与运行时；
* 工具只登记「元数据 + 构建闭包」，点开时才 new View，返回即释放；
* 所有位图解码带采样上限（长边 4096），图片运算全部在单线程后台队列执行，避免 OOM 与掉帧；
* 全局无图片缓存池、无字体资源、无动画框架依赖；
* 按 ABI 分包，单个安装包只含一种架构的原生库。

## 构建

```bash
export ANDROID_HOME=/path/to/sdk
./gradlew :app:assembleRelease
```

要求 JDK 17、Android SDK 36。签名密钥从 `signing/treasure-vault.jks` 读取；CI 由 Secrets 注入详见 [SIGNING.md](SIGNING.md)。
